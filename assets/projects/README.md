# Project images go here

Drop your project photos, screenshots or renders into this folder, then
reference them from `content.js`:

    image:   'assets/projects/my-project.jpg',
    gallery: ['assets/projects/my-project-2.jpg'],

Tips:
- Best size is about **1200 × 750 px** (a wide rectangle). JPG or PNG.
- Use lowercase filenames with dashes, no spaces: `solar-tracker.jpg`
- Keep files under ~500 KB so the page stays fast.
- No image yet? Leave `image: ''` — the site draws a clean cover for you.
